# Examples

Each example folder shows the same Port at one of the four projections.

## Hello-quilt (Python)

```bash
cd python
python hello.py
```

## Hello-quilt (Web)

```bash
cd web
python serve.py
# Browse to http://localhost:8787
```

## Hello-quilt (ESP32)

```bash
cd esp32
# Open sketch.ino in Arduino IDE
```

## Hello-quilt (Ideation)

```bash
cd ideation
python chat.py
```
